# Otterly Social Media Assets

## Profile pictures

| File | Platform | Usage |
|---|---|---|
| `profile/otterly-profile-light.png` | All | Light mode (default). Warm cream background. |
| `profile/otterly-profile-dark.png` | All | Dark mode variant. Deep teal background. |

Masters are 1024x1024. Platforms crop to their mask shape.

| `banner/otterly-banner-x-dark.png` | X/Twitter | 1500x500 |
