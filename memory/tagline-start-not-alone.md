The official positioning line for Otterly is "Start, Not Alone." The subtitle
is "Calm ADHD task starter." These come from the product docs
(`docs/design-handoff/psychology-and-product.md`).

Do not invent alternatives. "Your calm task companion" is not real copy.

**Why:** The psychology-and-product.md doc defines product positioning precisely.

**How to apply:** Use "Start, Not Alone." everywhere — social bios, banners,
marketing copy. Use "Calm ADHD task starter" as the category/subtitle.
